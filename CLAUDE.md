# Правила для агента

- Источник правды — SPEC.md. Нет сценария под задачу — сначала дописать сценарий, потом код.
- Работа только в ветке: `git switch -c feat/<задача>`. В main — через PR (гейт branch-guard).
- Каждый сценарий — тест в tests/. Тест не правится под код: расходится со спецификацией — права спецификация.
- Перед коммитом тесты гоняются сами (гейт test-gate). Красные — коммита нет.
- .env и ключи не читать (гейт secret-guard).
- Перед PR — субагент `judge`. PR только с вердиктом ПРИНЯТО.
- Окружение: `.venv/bin/python`, тесты — `.venv/bin/python -m pytest -q`.
